# Servicios Web - Página de Servicios Tecnológicos

Página web profesional para ofrecer servicios de:
- Servicio técnico informático
- Programación de sistemas a medida
- Inteligencia Artificial
- Redes y conectividad

## Estructura del Proyecto

```
servicios_web/
├── index.html          # Página principal
├── css/
│   └── estilos.css     # Estilos CSS
├── js/
│   └── main.js         # Funcionalidad JavaScript
├── images/             # Imágenes (para agregar logo, etc.)
└── README.md           # Este archivo
```

## Características

- **Diseño moderno y responsive** con gradientes y animaciones
- **Navegación suave** entre secciones
- **4 servicios principales** con descripciones detalladas
- **Formulario de contacto** funcional
- **Sección "Sobre nosotros"** con características destacadas
- **Optimizado para móviles** y tablets

## Cómo Usar

1. Abre el archivo `index.html` en tu navegador
2. Personaliza el contenido según tus necesidades:
   - Cambia el nombre de la empresa en el logo
   - Actualiza la información de contacto
   - Modifica los servicios según tu oferta
   - Agrega tu logo real en la carpeta images/

## Personalización

### Colores
Los colores principales están definidos en `css/estilos.css`:
- Gradiente principal: `#667eea` a `#764ba2`
- Puedes modificar estos valores para cambiar la paleta de colores

### Contacto
Actualiza la información de contacto en el HTML:
- Email: `contacto@techservices.com`
- Teléfono: `+1 234 567 890`
- Ubicación: Cambia a tu ciudad real

### Servicios
Modifica las descripciones de servicios en `index.html` para reflejar tus servicios reales.

## Tecnología

- HTML5
- CSS3 (con gradientes, grid, flexbox)
- JavaScript (ES6+)
- Diseño responsive
- Sin dependencias externas
